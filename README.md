# 🥗 ЧёПоел — Умный AI-дневник КБЖУ на Python (FastAPI + SQLAlchemy 2.0 + PostgreSQL / SQLite)

Полная серверная и десктопная версия умного дневника питания **«ЧёПоел» (v6.0)** на **Python**.

## 🛡️ 3-уровневая защита истории записей при обновлениях на GitHub (`git pull` / распаковка)

При обновлении кода репозитория ваша история приёмов пищи, воды, замеров веса, кастомных блюд, уровня XP и щитов заморозки **сохраняется на 100% автоматически**:

1. **Умное неразрушающее слияние (`backend/history_sync.py` + `mergeStatesNonDestructive`)**:
   - При каждом запуске и синхронизации сервер на Python и браузер сравнивают записи из `localStorage`, `IndexedDB (ChePoelDB)` и реляционной базы данных (`PostgreSQL` / `SQLite`).
   - Все исторические дни (`days`), приёмы пищи (`meals`), выпитая вода (`waterMl`), замеры веса (`weightLog`), созданные блюда (`customProducts`) и настройки профиля объединяются без затирания прошлых дат.
2. **Безопасная авто-миграция таблиц БД (`ensure_non_destructive_migrations`)**:
   - Таблицы никогда не пересоздаются через `DROP TABLE`. Недостающие колонки новой версии (`is_liquid`, `photo_b64`, `avatar_img_b64`, `banner_img_b64`, `freeze_used`, `penalty_redeemed`) добавляются на лету через `ALTER TABLE ... ADD COLUMN`.
   - Файлы базы данных (`*.db`, `*.sqlite3`, `data/*.db`) внесены в `.gitignore` и исключены из архива релиза, поэтому `git pull` или распаковка архива поверх папки проекта никогда не перезапишет вашу локальную базу.
3. **Независимое системное зеркало в профиле ОС (`~/.chepoel/chepoel_history_backup.json` / `%APPDATA%\ChePoel\chepoel_history_backup.json`)**:
   - Сервер на Python при каждом сохранении дублирует актуальный снимок вашей истории в системную папку пользователя ОС (вне папки Git-репозитория).
   - Даже если вы полностью удалите папку репозитория и клонируете её заново с GitHub (`git clone`), при первом же запуске Python-сервер автоматически восстановит все ваши аккаунты и историю записей в базу данных.

## 🐍 Отображение языка Python на GitHub + работа GitHub Pages

- В корень репозитория добавлен файл **`.gitattributes`**, который помечает статические ресурсы (`*.html`, `*.json`, `frontend/**`) как `linguist-vendored`. Благодаря этому **GitHub Linguist определяет язык репозитория как 100% Python**.
- Одновременно в корне и в папке `frontend/` находится актуальный `index.html`, поэтому при включении **GitHub Pages** веб-интерфейс также открывается напрямую по ссылке репозитория.

## 🚀 Быстрый запуск (3 способа на выбор)

### Способ 1. Мгновенный запуск одной командой (без установки зависимостей)
Работает на любом ПК с установленным Python 3.8+ (использует встроенную реляционную СУБД SQLite в 3НФ или автоматически запускает Uvicorn/FastAPI, если они установлены):
```bash
python app.py
```
*(На Windows можно просто дважды кликнуть по `start_windows.bat`, на macOS/Linux — `./start_mac_linux.sh`).*

### Способ 2. Полный стек FastAPI + SQLAlchemy 2.0 (PostgreSQL 16 или SQLite)
```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
По умолчанию используется локальная реляционная база `sqlite:///./data/chepoel.db` (7 таблиц в 3НФ). Для переключения на **PostgreSQL 16** задайте переменную окружения:
```bash
export DATABASE_URL="postgresql+psycopg2://chepoel_user:chepoel_pass@localhost:5432/chepoel_db"
```

### Способ 3. Запуск в Docker (FastAPI + PostgreSQL 16)
```bash
docker compose up -d --build
```
